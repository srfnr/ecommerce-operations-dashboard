E-Commerce Operations Dashboard
About the Project

I created this Power BI project to analyze sales and operational performance for an e-commerce business.

The dataset contains 1,000 orders with information about products, categories, customers, regions, warehouses, revenue, cost and delivery dates.

Key Findings
Electronics has the highest revenue and profit.
Stationery has the highest profit margin.
Laptop 14 is the top product in both revenue and profit.
Marmara has the highest regional revenue and profit.
Doğu Anadolu has the highest average delivery time.
İzmir warehouse has the highest revenue and profit.
Adana warehouse has the highest average delivery time.
